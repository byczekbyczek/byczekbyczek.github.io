A focused production path with a reason for every service.

The planned architecture separates capture, ingestion, event processing, historical analytics, and delivery so that each component can be benchmarked and scaled independently.

01 / EDGE Local parser

OpenCV and OCR convert permitted interface regions into structured events.

02 / INGEST Cloud Run API

A containerized FastAPI service validates and receives event payloads.

03 / STREAM Pub/Sub

Event delivery is decoupled from enrichment and analytical processing.

04 / ANALYZE BigQuery

Historical events support aggregate analysis and repeatable benchmarks.

05 / SERVE Analytics API

Low-latency responses and dashboards expose approved analytical outputs.

Responsible product scope

Compliance should be engineered and documented.

Koksu’s product scope should be defined around authorized data sources, minimal collection, publisher-specific review, and transparent controls.

Authorized workflows Support permitted coaching, analytical, tournament, broadcast, and post-match use cases.
Non-invasive product boundary No memory injection, anti-cheat bypass, account automation, or hidden client modification.
Data minimization Prefer structured events and avoid retaining raw frames unless retention is explicitly required and authorized.
Production safeguards Apply least-privilege access, encrypted transport, auditable operations, documented retention, and isolated testing.
